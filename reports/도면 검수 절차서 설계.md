# 3계층 체크리스트와 재질·FINISH 마스터로 도면 검수를 표준화

조사 기준일: 2026-10-28 · 대상: JUSTEM 반도체 장비 설계팀(FOUP/EFEM용 JFS 에어커튼, JPB N2 Purge 스토커, JDM 제습기 등) 제작도면 검수 절차서(도면화 검수 절차) 설계 · 근거: 외부 공개자료 조사 노트 4종(절차·General, DIVISION별, FINISH×재질, 반도체 재질·마스터 관리)

---

## 1. 결론 요약

- **결론**: 절차서는 "짧은 절차서 1부 + 별도 관리 체크리스트 양식 3계층(General / DIVISION별 / 프로젝트별) + 재질·FINISH 마스터(코드 사전)" 구조로 만들어야 함. NASA(절차서 ENG-I-SU03 + 별도 번호의 체크리스트 양식 ENG-F-SU01), MTS(검토 대상별 "해당 체크리스트" 적용) 사례가 같은 구조임 ([NASA ENG-I-SU03](https://www.nasa.gov/wp-content/uploads/2026/06/eng-i-su03-rev-3-space-utilization-quality-review-instruction.pdf), [MTS WI Rev H](https://training.mts.com/Engineering/Drawing_and_BOM_Checking_WI_RevH%20(changes%20highlighted).docx), 둘 다 검색 요약 근거).
- **General 체크리스트**는 공개 체크리스트들이 수렴하는 표제란·개정·투상/뷰·치수(누락·중복)·공차·GD&T(기하공차, Geometric Dimensioning and Tolerancing)·표면거칠기·재질/후처리·주서 9개 군을 모든 도면에 적용하고, 조립도에는 BOM·풍선 군을 추가함.
- **DIVISION별 체크리스트**는 공정 규칙(판금 굽힘, 용접기호, 나사 표기, 배관 사양)을 담음. **D 운동류·P 고정류는 "도면"이 아니라 "BOM 행"을 검토**함(메이커·전체 주문코드·수량·대체품 승인). ASME Y14.24의 VID(Vendor Item Drawing)/SCD(Source Control Drawing) 구분이 근거 틀임 ([DI-SESS-81000E](https://www.scribd.com/document/429161122/DI-SESS-81000E)).
- **재질·FINISH 불일치가 자동화 효과가 가장 큰 영역임**. 아노다이징은 알루미늄 전용, E.P(전해연마)는 스테인리스, 흑색산화피막·PARKERIZING·아연도금은 철강 전용이므로 FINISH×재질 매트릭스로 명백한 오류를 자동 반려할 수 있음 ([JIS H 8601:2025](https://webdesk.jsa.or.jp/preview/pre_jis_h_08601_000_000_2025_e_ed10_ch.pdf), [ASTM B912](https://standards.iteh.ai/catalog/standards/astm/c47c1db6-46fa-4eee-9ebf-b6639dca72f6/astm-b912-02-2018), [MIL-DTL-16232 가이드](https://hubbardhall.com/document/mil-dtl-16232g-specification-guide?dl=1)).
- **단, 사내 코드 사전 정비가 선행돼야 함**. FINISH 목록의 C.P·SILVER·투명·무정전·열처리,강화·E.P/POLYMER COATING(10um), 재질 목록의 TITANUM·NIKEL·SILICON CARBIRD·P.C·SS 41·중복(PET, SUS 310S)은 해석이 갈리므로 "확인 필요"로 묶어 담당자 확인 후 정규화해야 규칙 엔진이 오판하지 않음.
- **반도체 장비 특유 항목**(가스 접액부 316L·EP, 클린룸 플라스틱 난연 FM 4910/UL 2360, 아연·카드뮴 금지, 아웃개싱, FOUP 접촉부 ESD)은 General이 아닌 **프로젝트별 계층**에 두고 수치는 고객 사양에서 가져와야 함. 공개 SEMI 규격에는 EFEM용 도면 수준 수치가 거의 없음.
- **자동검사 범위**: 속성·재질·FINISH·BOM·개정·서식·판금 파라미터·용접 컷리스트는 SolidWorks API 추출 → JSON → Python 규칙 → Excel 검토표로 판정 가능. 기능·공차 적정성·데이텀·제작성·재질 적합성 판단은 사람이 함. 아키텍처는 기존 보고서(`CAD 도면 BOM 자동검토 GitHub 사례.md`)의 4계층 구조를 그대로 사용함.
- **도입 순서**: (1) 코드 사전·절차서·General 양식 → (2) 재질/FINISH/BOM 자동검사 → (3) DIVISION별 양식·판금/용접 규칙 → (4) 프로젝트 계층·지표 운영 순으로 4단계 권장.

## 3. 검토 체계: 3계층(General / DIVISION별 / 프로젝트별) 구조

### 3.1 계층 정의와 근거

- 공개 체크리스트는 표제란·개정·뷰·치수·공차·GD&T·주서·재질·BOM의 같은 항목군으로 수렴함(Five Flute, GD&T Basics, HII Navy 제출 가이드, MTS WI) ([Five Flute](https://www.fiveflute.com/assets/Five-Flute-Part-Drawing-Checklist-2022-12-03.pdf), [HII](https://hii.com/wp-content/uploads/2025/06/Navy_Approved_Drawing_Submittal_Guide.pdf), 검색 요약).
- 표준 체크리스트에 프로젝트 특유 항목을 **보충(supplement)** 하는 방식이 QMS 작업지침에서 확인됨 ([Drawing Checking Guide](https://www.scribd.com/document/708937622/Drawing-Checking-Guide), 출처 신뢰도 미확인).

| 계층 | 적용 범위 | 내용 성격 | 양식(제안) | 개정 주기(제안) |
|---|---|---|---|---|
| L1 General | 모든 도면(부품도·조립도) | 서식·표준 준수, 정보 완전성 | F-01 | 연 1회 + 반복불량 분석 시 |
| L2 DIVISION별 | 구매 분류 코드별 | 공정·구매 규칙(판금, 용접, 나사, 배관, 구매품 코드) | F-02-ASSY/M/F/S/T/D/P/Q/E | 연 1회 + 협력사 피드백 시 |
| L3 프로젝트별 | 제품군·고객·현장 | 고객 사양, 클린룸·진공·가스, ESD, 난연, 금지물질, 고객 지정 주서 | F-03-<프로젝트> | 프로젝트 착수 시 작성, 고객 사양 개정 시 |

- 각 체크리스트 사용 시 **양식 번호와 개정판을 검토 기록에 남김**(어떤 기준으로 검토했는지 추적).
- 연 1회 이상 체크리스트 재검토 권고가 검색 결과에 있으나 출처 귀속이 불명확함 → 주기는 결정 필요 항목으로 둠.

### 3.3 L3 프로젝트별 체크리스트(반도체 장비 특유 항목)

공개 SEMI/ISO 규격에서 EFEM·로드포트 퍼지·에어커튼에 직접 쓸 도면 수준 수치는 거의 없음. 아래 항목은 "규격명 표기 여부"를 검토하고 **수치는 고객 사양에서 가져옴**.

- 제품군별 적용 강도(제안, 결정 필요): JPB N2 Purge 스토커 = P-01·P-02·P-05·P-06 필수, JFS 에어커튼 = P-03·P-04·P-07 필수, JDM 제습기 = P-03·P-04 중심.

## 4. DIVISION별 도면 검토 체크리스트

### 4.1 DIVISION별 검토 대상·강도

| DIVISION | 검토 대상 | 강도 | 비고 |
|---|---|---|---|
| ASSY | 조립도 + BOM | 높음 | 모든 하위 DIVISION 코드 집계 지점 |
| M 일반가공품 | 제작도면 | 높음 | 공차·나사·후처리 핵심 |
| F 프레임(제관) | 용접 조립도 + 컷리스트 | 높음 | 용접기호·후가공 순서 |
| S 판금 | 제작도면 + 전개도(DXF) | 높음 | 굽힘 규칙 자동화 효과 큼 |
| T 배관 | 배관도·튜브 도면 + 피팅 BOM | 높음(퍼지 라인) | 등급(EP/BA/일반) 설계 결정 필요 |
| D 운동류 | **BOM 행**(구매 사양) | 중간 | 도면 대신 주문코드 검증 |
| P 고정류 | **BOM 행** | 중간 | 운동류 외 구매품 전체 |
| Q 셋업파트 | 식별·수량·설치 주서 | 낮음 | 의미 정의 확인 필요 |
| E 기타 | 식별·수량·도면 필요 여부 | 낮음 | 범위 정의 확인 필요 |
| X | 미정 | — | **의미 확인 필요**(참고용/검토 제외 추정) |

- ASSY·Q·E·X는 외부 공개 체크리스트가 발견되지 않음. ASME Y14.24의 조립도·설치도·Vendor Item Drawing 분류가 가장 가까운 틀임 ([CR4 Y14.24 토론](https://cr4.globalspec.com/thread/124228/ASME-Y14-24-Drawing-Types), 포럼 수준). 따라서 아래 항목 중 ASSY·Q·E는 사내 실무 기반 제안임.

### 4.2 ASSY

- BOM 완전성: 모든 구성품에 항목번호·사내 품번 또는 메이커 코드·수량·DIVISION 코드 존재.
- 풍선 ↔ BOM 항목 1:1, 수량 = 모델 수량.
- 간섭 검사(Interference Detection) 결과 미해명 간섭 0건.
- 메이트 오류·미출도 파일 외부참조 없음(Design Checker 조립 검사 항목) ([CATI Design Checker](https://www.cati.com/?p=132014)).
- 조립 주서: 체결 토크, 나사고정제·접착제(클린룸·아웃개싱 적합), 조립 순서·방향.
- 유지보수 접근성: 필터·팬·센서 교체 공간(에어커튼·제습기).
- 전형적 불량: 모델에 있으나 BOM 누락, Toolbox 체결품이 BOM 제외, 체결품 수량 오류, 하위 조립 개정 구판.

### 4.3 M 일반가공품

- 데이텀 체계(A/B/C)가 기능·상대부품과 일관.
- 공차의 기능 근거: "느슨하면 무엇이 고장나는가"로 비기능 공차 완화 ([dewin DFM](https://dewinvietnam.pages.dev/blog/dfm-checklist-metal-parts-vietnam), 업체 사례 — 단가 18% 절감 사례는 예시일 뿐).
- 나사 표기 형식(예: M10×1.5-6H), 반복형상 "4X", 막힌 탭은 최소 완전나사 깊이 지정 ([Fictiv](https://www.fictiv.com/articles/9-tips-for-better-engineering-drawings-that-save-time-money)).
- 각 형상은 실형이 보이는 뷰에서 1회만 치수 기입.
- 모서리 처리 일반주서, 후속 샌딩·코팅이 모서리에 미치는 영향 반영 ([Zimmer Group 요구 카탈로그](https://www.zimmer-group.com/fileadmin/daten/service/download-center/lieferanten/Requirements_catalog_for_drawing_parts__0538_EN.pdf)).
- 거칠기는 기능면만, 기본값 표기.
- 후처리 두께 여유: 도금·아노다이징 후 끼워맞춤·나사 영향(5.2절), 마스킹 지정.
- 전형적 불량: 과도한 일반공차, 나사 깊이 누락, 전 면 거칠기 지정, 코팅 여유 미반영.

### 4.4 F 프레임(제관)

- 용접기호 적용 규격 명기(ISO 2553 / AWS A2.4 / KS B 0052). ISO 2553은 화살표쪽·반대쪽 표기 체계가 2가지이므로 규격 명기가 필수 ([ISO 2553 BSI](https://knowledge.bsigroup.com/products/scheme-of-symbols-for-welding), [schematex 요약](https://schematex.js.org/ko/docs/welding)). KS B 0052의 ISO 2553 부합 여부는 확인 필요.
- 기본 필릿 크기 일반주서 존재.
- 용접 후 가공 순서, 가공 상태 뷰에서 가공면 식별, 가공 여유 — 외부 수치 근거 없음 → 결정 필요.
- 변형 관리: 응력제거, 용접 후 평면도.
- 용접기호는 모델 연동 기호 사용(수동 기호는 모델 변경 시 미갱신) ([Autodesk 용접 주석](https://help.autodesk.com/cloudhelp/2026/ENU/Inventor-Help/files/GUID-E3FB266D-8FE5-48B2-8761-137A4B323C25.htm)).
- 컷리스트: LENGTH·ANGLE1·ANGLE2·DESCRIPTION·MATERIAL·QUANTITY 자동 속성과 도면 표 일치. **폴더당 동일 바디만**(무게는 폴더 첫 바디로 계산) ([SOLIDWORKS 컷리스트 속성](https://help.solidworks.com/2023/english/SolidWorks/sldworks/t_custom_props_weldment_cut_lists_2.htm)).
- 알루미늄 프로파일: 시리즈·메이커 코드, 꼭지점 기준 전장, 절단·각도 공차, 단부 탭 크기·깊이(30계열 M8×16, 45계열 M12×24 예시), 절단면 무처리 여부 ([Ooznest 30x30](https://resources.ooznest.co.uk/aluminium-extrusion-system/aluminium-extrusion/30-series-t-slot-aluminium-extrusion/30x30mm-t-slot-aluminium-extrusion-profile-silver-cut-to-size-var-aep-t-3030-s-cts), [MISUMI](https://uk.misumi-ec.com/vona2/detail/110302687940)).

### 4.6 T 배관

- 튜브 외경·두께: 메이커 허용압력표에서 선정, 피팅 시험 범위 밖 두께 금지 ([Swagelok MS-01-107](https://www.swagelok.com.cn/downloads/webcatalogs/en/MS-01-107.pdf)).
- 굽힘부에서 피팅까지 최소 직관 길이, 튜브 끝 디버링.
- 재질·등급: 316L, EP 또는 BA, Ra 값 표기. 업체 사양 예: 내면 Ra ≤ 0.25 µm, 요청 시 0.13 µm ([Dockweiler](https://citech-c3.duckdns.org/file/DW_Specifications_ultron_EN.pdf)).
- 피팅 종류·메이커 코드(튜브 피팅 / VCR 면실 / 용접 피팅).
- 오비탈 용접 사양, 세정 등급·이중포장, He 리크 기준(팹 가스 시스템 통상 < 1×10⁻⁹ mbar·L/s) ([Inficon](https://www.ajvs.com/library/Inficon_UL_1000_Fab_Brochure.pdf)).
- 라인 식별(N2, CDA, 진공, 배기).
- **JPB N2 퍼지 라인 등급(UHP EP / BA / 일반)은 설계 결정 사항으로 도면에 기록**(추론, 결정 필요).
- 전형적 불량: 피팅 시험 범위 밖 두께, 리크 사양 누락, UHP 라인 나사 체결, BA·EP 혼용.

### 4.7 D 운동류(실린더·리니어 등 구매품)

- 검토 대상은 BOM 행: 메이커, **전체 주문코드**, 품명, 수량, 대체품 승인, 카탈로그 링크.
- 주문코드 전 필드 확인: 시리즈·마운팅·보어·스트로크·쿠션·오토스위치 모델·스위치 수량·주문제작 접미사(예: SMC -XB6, -XC6). "무기호(nil)"도 의미가 있음 ([SMC CP96](https://automationdistribution.com/content/files/pdf/cp96.pdf)).
- 메이커 컨피규레이터에서 코드 유효성 확인(SMC는 비호환 회색·충돌 적색 표시) ([smcpneumatics](https://www.smcpneumatics.com/53787.htm)).
- 3D 모델 스트로크 = 주문코드 스트로크.
- 하중·모멘트·수명 검토(LM 가이드, 볼스크류), 케이블 길이, 납기·단종 여부.
- 카탈로그 도면은 "참고/구매품"으로 표기, 사내 제작도면처럼 첨부 금지.
- **추가공한 구매품**(로드 끝 가공, MISUMI 추가공)은 M으로 이관하거나 VID 작성.
- 전형적 불량: 시리즈만 기재, 모델 스트로크와 코드 불일치, 스위치 누락, 주문제작 접미사 누락.

### 4.8 P 고정류(운동류 외 구매품)

- 체결품: 규격 번호(ISO 4762 / KS B 1003 대응은 확인 필요), 호칭×길이, 강도 등급·스테인리스 등급, 와셔·풀림방지.
- 나사 결합 길이 경험칙: 강 ≈1D, 알루미늄 ≈2D(Tameson: 강 1.0~1.5D, 알루미늄 2.0~2.5D) ([Nord-Lock](https://www.nord-lock.com/insights/bolting-tips/2015/the-experts-thread-engagement-in-a-tapped-hole/), [Tameson](https://tameson.com/thread-engagement-chart.html)) → 사내 최소값 결정 필요.
- 클린룸 영역 체결품 표면처리: 아연도금 배제(P-04).
- 피팅·센서·필터·팬 등 기타 구매품: 메이커 코드·대체품·납기.
- Toolbox 체결품은 구성별 사내 품번·품명 보유 ([SOLIDWORKS Toolbox 구성](https://help.solidworks.com/2024/English/Solidworks/sldworks/HIDD_DVE_TOOLBOXSIZER.htm)).
- 전형적 불량: 막힌 탭 바닥 닿음, 알루미늄 결합 길이 부족, 클린룸 내 도금 볼트, BOM에 너트·와셔 누락.

### 4.9 Q 셋업파트 / E 기타 / X

- 경량 검토: 식별(품번·메이커 코드), 수량, 도면 필요 여부, 설치·현장맞춤 주서(심, 레벨링 풋, 앵커, 케이블 트레이).
- Q·E·X의 정의와 검토 제외 조건은 사내 확정 필요. X는 "참고용/검토 제외"로 추정되나 외부 근거 없음.

| 탈지 | 세정 공정(피막 아님) | 전 재질 | 진공 부품은 정밀세정 사양 별도 |
| 무정전 | 대전방지 코팅 추정 | 플라스틱(PC·ACRYL·PET) | **확인 필요**(표면저항 명시) |
| 열처리,강화 | 강의 담금질·뜨임 / 유리 강화 | 강·유리 | **확인 필요**(코드 2개 분리 제안) |
| - / None | 무처리 | — | **확인 필요**("의도적 무처리" vs "미입력" 구분) |

- 출처: 아노다이징 규격은 알루미늄·알루미늄 합금 대상 ([JIS H 8601:2025](https://webdesk.jsa.or.jp/preview/pre_jis_h_08601_000_000_2025_e_ed10_ch.pdf), [KS D 8301](https://ndls.org.cn/standard/detail/5dde45d38130caa1f698b2dfb386c362)); 흑색산화피막 철강 한정 ([MIL-DTL-13924D](https://www.scribd.com/document/515535470/MIL-DTL-13924D)); PARKERIZING은 Al·황동·동 불가, 스테인리스 부적합 ([HMSC](https://homemetalshopclub.org/news/14/parkerizing.pdf)); E.P는 200·300·400계·PH 스테인리스 대상 ([ASTM B912](https://standards.iteh.ai/catalog/standards/astm/c47c1db6-46fa-4eee-9ebf-b6639dca72f6/astm-b912-02-2018)).
- 해석 근거의 대부분은 검색 요약 및 연구자 추론임. 확인 필요 코드는 도면 작성자·후처리 협력사 확인 전 자동 판정에서 "경고"로만 처리.

### 5.2 도면 표기 요건(FINISH 주서 구성)

- 필수 요소: **규격 + Type/Class + 두께(최소/최대) + 색상 + 봉공(seal) + 마스킹·유효면 + 치수 적용 시점(처리 전/후) + 수소취성 베이킹(해당 시)**.
- 근거: ASTM B733은 유효면·응력제거·취성제거 등 여러 항목을 구매자 지정으로 남기므로 규격 번호만으로는 불완전함 ([Gleco](https://glecoplating.com/?p=992)). 도면에 없는 봉공을 업체가 추가해 7075 색상이 달라진 사례가 있음 ([finishing.com 549/81](https://finishing.com/549/81.shtml)).
- 치수 영향: 경질 아노다이징은 약 50% 외부 성장·50% 내부 침투 ([finishing.com 74/29](https://www.finishing.com/74/29.shtml)); 경질 크롬은 과도금 후 연삭 ([NASA PRC-5003](https://www.nasa.gov/wp-content/uploads/2023/03/prc-5003-current.pdf)).
- 나사 영향(일반 공학 관행, 출처 미확보): 60° 나사 유효경 변화 ≈ 4 × 면당 두께 → 나사 마스킹 또는 "처리 후 치수" 명기.
- 주서 예시(규격 개정판 확인 필요):
  - 경질 아노다이징: `HARD ANODIZE PER MIL-A-8625 TYPE III, CLASS 1, 50 ±10 µm, [JIS H 8603]. MASK THREADS AND ⌀__H7 FITS.` — 두께값은 예시, MIL-A-8625 원문 확인 필요.
  - 무전해니켈: `ELECTROLESS NICKEL PER ASTM B733, TYPE __, SC2 (13 µm MIN), CLASS 1. DIMENSIONS APPLY AFTER PLATING.` (SC 두께 구분 근거: [Gleco](https://glecoplating.com/?p=992))
  - EP: `ELECTROPOLISH PER ASTM B912; Ra ≤ __ µm (SEMI F19, 고객값).`
  - RAYDENT: `RAYDENT TREATMENT, BLACK` + 치수여유 업체 확인 필요.

### 5.3 FINISH 도면 ↔ BOM 일치 검토 규칙

| 규칙 | 내용 | 판정 |
|---|---|---|
| F-R1 | 도면 표제란 FINISH = 모델 FINISH 속성 = BOM FINISH 열 = ERP 품목 FINISH 코드 | 자동(불일치 = 오류) |

### 5.5 자동 반려 규칙과 진공·클린룸 경고

- 자동 반려(❌) 후보:
  - ANOD. 계열 코드를 비알루미늄 재질에 지정.
  - PARKERIZING·흑색산화피막을 Al·Cu 합금·Ti·W·Mo·플라스틱·유리에 지정(Cu 흑색화는 별도 규격으로 사람 검토).
  - 아연도금을 SUS·Al·Cu 합금에 지정.
  - 탈지·무정전(플라스틱)·강화(유리) 외 화학·전기화학 처리를 플라스틱·유리·세라믹·엘라스토머에 지정.
  - E.P를 탄소강·SPCC·FC300에 지정.
  - 열처리(경화)를 SS 41·SPCC·AL 5052·오스테나이트 SUS에 지정.
- 진공·클린룸 경고(L3 계층):
  - 아연·카드뮴: 진공에서 승화, 전도성 증착물·위스커 ([NASA 아연](https://nepp.nasa.gov/npsl/Prohibited/zinc_prohibition.htm), [NASA 카드뮴](https://nepp.nasa.gov/npsl/Prohibited/cadmium_prohibition.htm)).
  - 아노다이징: 다공성 산화막이 수분 보유 → 무베이킹 아노다이징 Al은 1 h에 일반 Al 대비 약 41배, 10 h에 약 71배 아웃개싱 ([Ideal Vacuum 백서](https://www.idealvac.com/files/manuals/White-Paper-Welded-Vac-Chamber.pdf)). 염색 BLACK-ANOD.는 진공부 경고.
  - 흑색산화피막·RAYDENT: 오일 보조처리 의존(RAYDENT 70~90일 오일링 권고) → 탄화수소·파티클 위험 ([IPROS](https://mono.ipros.com/en/cg1/Raydent%20Treatment/)).
  - PAINT, Vibrator·SANDING: 아웃개싱·매립 연마재 → 후 정밀세정 요구.
  - 탈지 단독은 청정도 사양이 아님 → 진공부 정밀세정 등급은 고객 사양 확인 필요.

## 6. 재질 ↔ BOM 일치 검토 방법

### 6.1 단일 재질 마스터(진실 원천) 구조

- 원칙: 재질 마스터 1개를 기준으로 (a) 읽기전용 공유 .sldmat 라이브러리, (b) PDM 데이터카드/Property Tab Builder 목록, (c) ERP 품목 마스터를 **생성·동기화**함. 설계자 직접 타이핑 금지.
- 근거: .sldmat는 File Locations > Material Databases로 공유, 사용자 읽기·관리자 쓰기 권한 관행 ([Solid Solutions](https://solidsolutions.co.uk/Blog/2021/09/Creating-custom-material-libraries-in-SOLIDWORKS), [CADimensions](https://knowledge.cadimensions.com/knowledge/how-can-i-create-a-custom-material-database-in-solidworks)). PDM 카드 목록은 외부 DB의 SQL 쿼리로 채울 수 있음 ([SOLIDWORKS PDM SQL 목록](https://help.solidworks.com/2017/English/EnterprisePDM/Admin/t_create_SQL_list.htm), [Javelin 2024](https://www.javelin-tech.com/blog/2024/09/creating-a-card-list-from-an-sql-database-in-solidworks-pdm/)).

| 마스터 열(제안) | 예 | 용도 |
|---|---|---|
| MAT_CODE | ERP 키(불변) | ERP 연동 |
| CANONICAL_NAME | STS304 / SUS304 중 사내 결정 | 표기 통일 |
| STANDARD / GRADE / TEMPER | KS D 3698 / STS304 / 2B, A6061-T6/T651 | 규격 명기 |
| SW_MATERIAL_NAME | .sldmat 정확 명칭 | SW 대조 |
| ALIASES | SUS 304, SUS304, 304 | 정규화 |
| CATEGORY | 금속/플라스틱/세라믹/엘라스토머 | 매트릭스 연동 |
| WETTED_OK / FM4910 / ESD_CLASS | Y/N | L3 규칙 |
| STATUS | 사용/폐지/대체(→코드) | 구 규격 차단 |

- FINISH는 재질 문자열에 붙이지 않고 별도 통제 필드로 관리(예: NIKEL이 도금 의미면 FINISH로 이관).

### 6.2 4자 일치 검증 규칙

| 규칙 | 비교 대상 | 판정 |
|---|---|---|
| M-R1 | 제작품의 SW 재질이 마스터에 존재·비공란, 기본값 "Material <not specified>" 금지 | 오류 |

- 근거: 구성별 링크 문법 `"SW-Material@@Config@Part.SLDPRT"`(따옴표 필수, 2015년 포럼 근거 → 현행 버전 확인 필요) ([3DSwym](https://3dswym.3dexperience.3ds.com/question/solidworks-user-forum/linking-to-material-custom-property_I8hP3AT9TT2X2i-4h0d5Xw)); 속성 드롭다운 추가 시 SW 재질 링크가 끊김 ([myCAD 포럼](https://forum.mycad.visiativ.com/t/piloter-la-matiere-piece-depuis-un-formulaire-de-proprietes-personnalisees/98053)).
- 함정(절차서에 명기):
  - BOM이 캐시값을 표시 → 부품 열기·BOM 갱신 전 불일치 ([eng-tips](https://www.eng-tips.com/threads/bom-showing-incorrect-info.333177)).
  - Excel BOM이 "SW-Material" 문자열 그대로 표시 ([SOLIDWORKS 포럼](https://forum.solidworks.com/forum-solidworks/ghuvLx8_S92gTC5TKjXtPA/excel-bom-table-shows-sw-material-instead-of-material-text)).
  - 수량 등 속성 수기 덮어쓰기 ([Solid Solutions](https://www.solidsolutions.co.uk/tech-support-blog-why-are-my-bom-quantities-wrong/)).
  - .sldmat 항목 이름 변경 시 기존 부품 재질 고아화 → 별칭·마이그레이션 경유.
  - 도면은 `$PRPSHEET:"Material"`, BOM은 "재질" 등 속성명 불일치.
  - 용접 컷리스트·파생/대칭 부품의 자체 재질 속성.
- 원천 우선순위·추출 방식(API vs Document Manager, 키 기반 외부조인)은 기존 보고서 3.1·5.4절 설계를 재사용.

## 7. 절차서 구조(목적·범위·책임·절차·체크리스트·기록·개정관리)

### 7.1 문서 체계

| 문서 | 내용 | 비고 |
|---|---|---|
| 절차서(QP-ENG-xxx) | 목적·범위·정의·책임·흐름·기록·개정 | 짧게 유지 |
| 작업지침(WI) | 검도 방법: 마킹 색상, 백체크, 자동검사 실행·결과 처리 | — |
| F-01 General 체크리스트 | 3.2절 | 양식별 독립 개정 |
| F-02-<DIVISION> | 4장 | 〃 |
| F-03-<프로젝트> | 3.3절 | 프로젝트 착수 시 |
| 부속서: 재질 마스터·FINISH 코드 사전·FINISH×재질 매트릭스·결정 기준값표 | 5·6·9장 | 규칙 엔진의 입력 데이터 |

### 7.2 절차서 목차(안)

1. 목적: 제작도면·BOM의 출도 전 검증으로 제작·구매 오류 예방.
2. 적용 범위: 사내 설계 제작도면(ASSY, M, F, S, T), 구매품 BOM 행(D, P), Q·E·X(경량 검토), 설계 변경(ECO) 재검토.
3. 용어 정의: 검도, 백체크, DIVISION, FINISH, 결함 등급, VID.
4. 책임과 권한(7.3절 RACI).
5. 절차(7.4절 흐름).
6. 체크리스트 적용 규칙: L1 + 해당 L2 + 해당 L3, 사용 양식 개정판 기록.
7. 결함 등급·출도 기준(7.5절).
8. 기록 및 보존.
9. 개정 관리: 절차서·양식·코드 사전 각각 개정 이력, 반복 결함 분석 반영.
10. 관련 문서: ISO 9001, ASME Y14 계열, KS B 0001, 고객 사양, 기존 자동검토 보고서.

### 7.3 책임(RACI, 제안)

| 활동 | 설계자(작성) | 검도자 | 승인자(팀장) | PDM/문서관리 | 생산·QC·구매 | 고객 |
|---|---|---|---|---|---|---|
| 자가검토·자동검사 실행·결과 첨부 | R | I | — | — | — | — |
| 독립 검도·레드라인·체크리스트 서명 | C | R | I | — | C | — |
| 수정·백체크 | R(수정) | R(확인) | — | — | — | — |
| 출도 승인 | — | C | A | — | — | C/I(계약 시) |
| 출도·번호·배포 | — | — | I | R | I | — |
| 코드 사전·매트릭스 유지 | C | C | A | R | C(후처리·구매) | — |

- 검도자는 작성자가 아니어야 함(독립성) ([lx.iriss.org.uk](https://www.lx.iriss.org.uk/read/drawing-checking.html), 저신뢰 출처 — 일반 원칙으로만 인용).
- MTS는 검토자가 담당 엔지니어면 ENGR란, 타인이면 CHECK란에 서명 → 소규모 팀에서 자가검토 허용 범위를 정할 때 참고 ([MTS WI Rev G](https://training.mts.com/Engineering/Drawing_and_BOM_Checking_WI_RevG%20-%20ENGR015_OLT.pdf), 검색 요약). 자가검도 허용 여부는 결정 필요.

### 7.4 흐름

1. 작성 → 2. 자가검토(F-01/F-02) + 자동검사 → Excel 검토표 첨부 → 3. 검도 요청 → 4. 검도자 레드라인(PDF 마크업) → 5. 설계자 수정 → 6. 백체크(레드라인 항목별 확인) → 7. 승인 → 8. PDM 개정 출도·배포.
- 설계 변경: ECR → ECO → 개정 도면(개정표 기재) → **변경 부위와 영향 범위만 재검도**.
- 마킹 색상(사실상 표준): 노랑 = 확인 완료, 빨강 = 추가·수정, 초록 = 삭제/수정자 지시 ([WSDOT M3082 App. E](https://wsdot.Wa.Gov/publications/manuals/fulltext/M3082/AppendixE.pdf), [배관 검도 색상](https://www.scribd.com/document/361812111/CheckingColorCode-pdf)).
- 체크리스트 응답: 작성자·검도자가 각각 Y/N/NA 기입 ([EXPRO 양식](https://www.expro.gov.sa/api/uploads/Checklist%20%20General%20Notes%20Drawing%20Template.docx)).

### 7.5 결함 등급·기록·지표

- 결함 등급(권위 있는 공개 기준 없음, 제안 → 결정 필요):
  - A(치명): 기능·안전·끼워맞춤 오류, 잘못된 공차·재질·FINISH → 출도 불가.
  - B(중대): 협력사 문의(RFI)를 유발하는 정보 누락·모호성.
  - C(경미): 서식·오탈자.
  - 출도 기준: A·B 미결 0건, C 처리 결정 완료.
- 기록: 서명된 체크리스트(양식 개정판 포함), 레드라인 PDF, 자동검사 Excel 검토표, DR 회의록, ECR/ECO, 출도 이력(누가·언제·개정).
- 지표:
  - FPY(First Pass Yield) = 1차 검도 승인 도면 수 ÷ 제출 도면 수(재작업은 실패로 계산) ([6sigma.us](https://www.6sigma.us/manufacturing/first-pass-yield-fpy/)).
  - 도면당 결함 수(등급·분류별), 검도 리드타임, 자동검사 1차 통과율.
  - 출도 후 유출: 도면 오류 기인 ECO, 협력사 RFI, 부적합(NCR).
  - 결함 분류 → 반복 원인을 템플릿·체크리스트로 환류(반도체 장비사 FPY 연구에서 제안) ([MIT DSpace](https://dspace.mit.edu/handle/1721.1/107027?show=full)).
  - 업계 벤치마크 값은 발견되지 않음 → 목표값 결정 필요.

### 7.6 ISO 9001 대응(조항 번호는 원문 확인 필요)

| 절차 요소 | ISO 9001:2015 조항(배경지식) |
|---|---|
| 도면 검도 = 설계 출력이 입력을 충족하는지 검증(verification) | 8.3.4 ([open-exam-prep](https://open-exam-prep.com/study-guides/iso-9001-lead-auditor/chapter-2b/section-2-3), 2차 자료) |
| 도면 = 설계 출력(합격 기준 포함) | 8.3.5 |
| ECR/ECO | 8.3.6 |
| 절차서·체크리스트·코드 사전 개정 관리 | 7.5.3 |
| 검토·검증 활동의 문서화된 정보 보유 | 8.3.4 ([Presencis 요약](https://cdn.presencis.com/regulations/iso-9001/article-8.3/)) |

- ISO 9001은 체크리스트 형식을 규정하지 않음. 계획·통제·기록 보유만 요구.

## 8. 자동검사 vs 사람 검토 구분

- 구조: SolidWorks API 추출 → JSON → Python 결정론적 규칙 → Excel 검토표, Design Checker는 서식·단일문서 검사로 병행. LLM은 판정 금지·설명 보조만 허용(근거·아키텍처는 기존 보고서 5.2절 참조).

|---|---|---|---|
| 표제란·속성 | 필수 속성 존재·형식, 품번↔파일명↔PDM, 개정 일치 | — | — |
| 서식 | 템플릿 버전, 글꼴, 단위, 투상법, override·Dangling 치수(Design Checker) | — | — |
| 치수·공차 | 일반공차 주서 존재, Hole Wizard 사용 여부 | 누락·중복 치수 후보, 끼워맞춤 표기 존재 | 공차 적정성·누적, 데이텀 기능성, 뷰 충분성 |

| D/P 구매품 | 필수 필드, Toolbox 사내 품번 | 메이커별 코드 정규식 | 컨피규레이터 검증, 하중·수명, 결합 길이 |
| L3 프로젝트 | 영역 속성 기반 금지 FINISH·재질, FM4910·ESD 필드 존재 | — | 고객 사양 해석 |

- 근거: Design Checker는 치수 표준·사용자 속성·단위·글꼴·override 치수·시트 포맷·재질·메이트 오류·외부참조 검사 가능 ([SOLIDWORKS Design Checker](https://help.solidworks.com/2025/English/swconntutorial/Design_Checker_Overview.htm)). 표준 구멍 검사가 Hole Wizard 구멍을 전부 사용자 정의로 표시한 포럼 보고 있음 → 시범 검증 필요 ([3DSwym](https://3dswym.3dexperience.3ds.com/question/solidworks-user-forum/hole-wizard-and-bend-surfaces_H-G_7xPjRqiiwtTd7j333A)). 판금 굽힘 R은 API로 읽기 가능 ([SW API BendRadius](https://help.solidworks.com/2017/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.ISheetMetalFeatureData~BendRadius.html)). Hole Wizard 파라미터 API(`IWizardHoleFeatureData2`)는 이번 조사에서 미확인 → 확인 필요.
- **자동검사 전제조건**: 재질 마스터·FINISH 코드 사전·매트릭스·판금 기준값이 데이터 파일로 확정돼야 규칙이 판정 가능. 따라서 9장 결정 항목이 자동화의 선행 과제임.

## 11. 단계별 도입안

| 단계 | 기간(제안) | 산출물 | 완료 기준 |
|---|---|---|---|
| 1. 기준 정비 | 1~2개월 | 절차서 초안, F-01 General 양식, 재질 마스터·FINISH 코드 사전(확인 필요 항목 해소), 결함 등급 | 확인 필요 목록 담당자 회신 완료, 수기 검도 시범 운영 |
| 2. 재질·FINISH·BOM 자동검사 | 2~3개월 | M-R/F-R 규칙, 매트릭스 데이터 파일, Excel 검토표, Design Checker .swstd 서식 기준 | 시범 프로젝트 도면 전수 실행, 오탐률 검토 |
| 3. DIVISION별 확장 | 2~3개월 | F-02 양식 9종, 판금·제관 규칙(굽힘 R, K-factor, 컷리스트), D/P 코드 정규식 | 판금·제관 협력사 기준값 합의 |
| 4. 프로젝트 계층·지표 운영 | 상시 | F-03(JFS/JPB/JDM), FPY·결함 대시보드, 연 1회 체크리스트 개정 | 분기별 반복 결함 환류 |

- 단계 1 이전에 자동화를 시작하지 않음: 코드 사전 없이 규칙을 만들면 사내 표기 편차(예: `-`/None, SUS 310S 중복)가 오탐으로 쏟아짐.
- 판금 기준값은 협력사 실측(시험 굽힘) 근거로 확정 → 외부 지침 값은 상충하므로 그대로 채택하지 않음.
